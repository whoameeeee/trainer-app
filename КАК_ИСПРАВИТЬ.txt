Продвижение 6.7.1 — исправление создания студии.

1. Сохраните предыдущий ZIP и резервную копию Supabase.
2. В Supabase → SQL Editor → New query выполните целиком ИСПРАВЛЕНИЕ_СОЗДАНИЯ_СТУДИИ.sql.
3. В config.js перенесите ваш действующий sb_publishable_ ключ из предыдущей версии.
4. Загрузите файлы приложения в корень GitHub-репозитория, заменив старые. SQL и TXT можно не загружать.
5. Дождитесь публикации GitHub Pages, обновите страницу и нажмите «Создать студию как владелец».
6. Если снова возникнет ошибка, пришлите её точный текст. Не отключайте RLS.

Это точечное исправление создания студии, а не подтверждение готовности финансовой системы для реальных денег.
