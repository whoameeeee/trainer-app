ПРОДВИЖЕНИЕ 5.0 — Android PWA

1. Сохраните резервную копию из версии 4.5.
2. В config.js перенесите свой существующий sb_publishable_ ключ. Не используйте secret key.
3. Замените файлы в корне репозитория GitHub Pages, дождитесь публикации.
4. Откройте приложение в Chrome на Android с интернетом, войдите и дождитесь загрузки данных.
5. Меню Chrome (⋮) → Установить приложение / Добавить на главный экран.
6. Нажмите «Напоминания» и разрешите уведомления. Напоминания срабатывают за час, пока приложение открыто; это НЕ фоновые push.
7. Для проверки офлайн сначала один раз откройте приложение с интернетом, затем включите режим полёта и откройте календарь.
8. Офлайн можно добавлять клиентов и новые тренировки. После подключения нажмите «Синхронизировать». Редактирование существующих облачных записей, удаление и оплаты требуют сети.

ОГРАНИЧЕНИЯ: первоначальный вход и загрузка SDK требуют интернета; для повторного запуска офлайн браузер должен успеть закешировать SDK и оболочку. Данные сохраняются в localStorage этого устройства и аккаунта; не очищайте данные сайта. Одновременные изменения на нескольких устройствах не имеют разрешения конфликтов. Уведомления при закрытом приложении потребуют отдельной серверной push-инфраструктуры. Перед реальным использованием проверьте резервную копию, синхронизацию и безопасность телефона.
