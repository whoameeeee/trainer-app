TRAINER APP 4.1 — вход и восстановление пароля

1. Важно: сохраните свой действующий config.js с ключом sb_publishable_... или вставьте этот ключ в config.js из архива. НЕЛЬЗЯ использовать sb_secret_.
2. Загрузите index.html, config.js, manifest.json, sw.js в корень репозитория GitHub Pages, заменив старые файлы.
3. В Supabase откройте Authentication → URL Configuration. В Site URL укажите полный адрес сайта GitHub Pages (например https://username.github.io/trainer-app/). В Redirect URLs добавьте тот же адрес.
4. При восстановлении нажмите «Забыли пароль?», введите email, откройте письмо, задайте новый пароль и войдите.
5. Если после обновления показывается старый экран, обновите страницу без кэша или откройте сайт в приватной вкладке.

Облачные данные остаются в Supabase. Данные старой версии 3.0 из localStorage автоматически не переносятся.
