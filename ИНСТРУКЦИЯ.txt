ПРОДВИЖЕНИЕ 4.5 — версия для показа

1. Откройте config.js и вставьте прежний ключ sb_publishable_... вместо PASTE_YOUR_SB_PUBLISHABLE_KEY_HERE. НЕ вставляйте sb_secret_.
2. Загрузите содержимое этой папки в корень репозитория GitHub Pages, заменив старые файлы. Не загружайте ZIP как один файл.
3. Подождите публикации GitHub Pages. Откройте сайт, обновите страницу (Ctrl+F5), на телефоне при необходимости закройте и откройте приложение.
4. Войдите в существующий аккаунт. Не создавайте новый аккаунт для доступа к старым клиентам.
5. Проверьте на тестовом клиенте: добавить клиента, записать тренировку, отметить оплату, обновить страницу.
6. На главной можно скачать резервную копию JSON и таблицу CSV. В ежедневнике можно распечатать день или выгрузить расписание CSV.

ВАЖНО: доступ к облачным данным и сохранение изменений требуют интернета. Сервис-воркер кэширует оболочку сайта, но полноценное автономное редактирование и синхронизация пока не реализованы. Push-уведомлений пока нет. Автоматические резервные копии Supabase зависят от тарифа; ручная выгрузка в приложении не заменяет серверные резервные копии. Временная иконка с буквой П — замените на свой логотип позже. JSON — ручная копия для сохранения; автоматический импорт JSON в этой версии отсутствует.
